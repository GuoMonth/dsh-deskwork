## English

DSH Deskwork 0.2.3 aligns with pinned **DSH 0.2.1-rc.3**, the prerelease currently shipped by the official desktop update feed. Upstream DSH remains a prerelease.

- Conversation recovery now uses the official SDK `session/resume` and `session/prompt` methods. Deskwork removed its local resume adapter; restarting a task continues the stored native session without replaying chat text, and a missing log is still reported instead of silently starting a new agent.
- The minimal DSH bundle in 0.2.1 is a coding-agent profile. Deskwork keeps its website-workbench tool surface: shell, PTY, editor, file-reading and working-directory tools stay disabled, while official automatic context compaction, token metering and image offload remain available. Long conversations may therefore use summarized model-visible history; the durable session log and the on-screen conversation retain their events.
- Runtime baselines follow the official desktop: Electron **44.7.0** (embedded Node **24.21.0**), electron-builder **26.17.0**, pnpm **11.28.5**, Cordis **4.0.5** and `cordis-plugin-group` **1.0.5**. Packaged runtimes also omit upstream build-only files such as node-pty ConPTY sources and debug symbols.
- ERP integration moves to **0.1.2**, verified with the same DSH prerelease. SDK and Devkit assets are **0.1.0-alpha.4**; they remain installable TGZ files whose npm package names are not published.
- Some public marketplace plugins still declare peer ranges ending below DSH 0.2.0. DSH 0.2.1-rc.3 rejects those packages through its version gate; this release respects that gate and makes no positive market-install claim for them.
- Browser control, native approvals, plugin installation and the one-task-at-a-time workflow are unchanged. When a task is stopped, a pending approval is still cancelled and cannot execute; the cancellation is recorded in the durable session log even though shutdown no longer delivers a live event for it.

Download [macOS Apple Silicon (arm64) DMG](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/DSH-Deskwork-mac-arm64.dmg) or the [Linux x64 portable archive](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/DSH-Deskwork-linux-x64.tar.gz). macOS supports Apple Silicon only. Both packages include their own runtime and pnpm. Drag the macOS app into Applications; on Linux, extract and run `./linux-unpacked/dsh-deskwork`.

Checksums are in [SHA256SUMS](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/SHA256SUMS); [release-manifest.json](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/release-manifest.json) records the source commit, runtime versions and verification runs. Only desktop binaries, SDK/Devkit packages and integrity metadata are distributed.

Verification covers standard checks, runtime and desktop integrations, native approvals, plugin installation, external development, locale behavior, the published ERP 0.1.2 consumer, and the sealed packaged runtime. The macOS arm64 DMG is mounted and installed outside the build directory, its signature is checked, and its packaged runtime is exercised without a system Node or pnpm on PATH. Uploaded asset hashes are checked before publication.

macOS uses ad-hoc signing; Developer ID signing and Apple notarization are not configured. Verification uses deterministic models and synthetic websites. Live-model business tasks, real ERP writes and user macOS acceptance remain pending. Local plugins execute trusted code with access to files and the network.

## 中文

DSH Deskwork 0.2.3 对齐固定的 **DSH 0.2.1-rc.3**，即官方桌面更新源当前发布的预发布版本。DSH 上游仍为预发布版本。

- 会话恢复改用官方 SDK 的 `session/resume` 与 `session/prompt`。Deskwork 删除了本地恢复适配层；重新开始任务会继续已保存的原生会话，不重放聊天文字；原生日志缺失时仍明确报错，不会静默创建替代会话。
- 0.2.1 的最小 DSH bundle 是编码 Agent 组合。Deskwork 保持网站工作台的工具面：shell、PTY、编辑器、文件读取和工作目录工具继续关闭；保留官方的自动上下文压缩、token 计量与图片卸载。长对话的模型可见历史可能被摘要替换，持久会话日志与界面历史仍保留原事件。
- 运行时基线跟随官方桌面：Electron **44.7.0**（内嵌 Node **24.21.0**）、electron-builder **26.17.0**、pnpm **11.28.5**、Cordis **4.0.5** 与 `cordis-plugin-group` **1.0.5**。随包运行时同时省略 node-pty ConPTY 源码、调试符号等上游构建文件。
- ERP 集成升级到 **0.1.2**，与宿主使用同一 DSH 预发布版本验证。SDK 与 Devkit 为 **0.1.0-alpha.4**，仍以可安装 TGZ 分发，其 npm 包名尚未发布。
- 公开市场仍列有 peer 范围低于 DSH 0.2.0 的插件。DSH 0.2.1-rc.3 会通过版本门禁拒绝这些包；本版本不绕过门禁，也不声称这些插件可安装。
- 浏览器操作、原生审批、插件安装和单任务工作流保持不变。停止任务时，待确认操作仍会被取消且不能执行；关闭过程不再实时发送该事件，但取消结果记录在持久会话日志中。

下载 [macOS Apple Silicon（arm64）DMG](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/DSH-Deskwork-mac-arm64.dmg) 或 [Linux x64 便携包](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/DSH-Deskwork-linux-x64.tar.gz)。macOS 仅支持 Apple Silicon。两种桌面包均包含独立运行时与 pnpm。macOS 将应用拖入 Applications；Linux 解压后运行 `./linux-unpacked/dsh-deskwork`。

校验值见 [SHA256SUMS](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/SHA256SUMS)，[release-manifest.json](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.3/release-manifest.json) 记录源码提交、运行时版本与验证运行。发布资产仅含桌面二进制、SDK/Devkit 包与完整性元数据。

验证覆盖标准检查、运行时与桌面集成、原生审批、插件安装、外部开发连接、语言行为、已发布 ERP 0.1.2 消费方，以及封装后的随包运行时。macOS arm64 DMG 挂载后安装至构建目录外，校验签名，并在 PATH 不含系统 Node 或 pnpm 时验证随包运行时。发布前核对上传制品摘要。

macOS 使用临时签名，尚无 Developer ID 签名和 Apple 公证。验证使用确定性模型及合成网站；真实模型业务任务、真实 ERP 写入和用户 macOS 实机验收仍待完成。本地插件执行可信代码，可访问文件和网络。
