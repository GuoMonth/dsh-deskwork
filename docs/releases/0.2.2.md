## English

DSH Deskwork 0.2.2 completes the native-session and approval integration with pinned **DSH 0.2.0-rc.2**. Upstream DSH remains a prerelease.

- Conversations preserve native DSH tool history across restart. Tasks stay paused until you observe the page and continue; previous approvals expire. A new task starts a separate session. Older text-only conversations remain visible, with an explanation that their tool history cannot be restored.
- Critical browser and plugin actions use native DSH approvals. Stopping or rejecting a task prevents the pending action; approval does not require another model turn.
- Plugins receive a generic website context and report their actual load state. Failed plugin updates preserve the previous installation. ERP **0.1.1**, published through npm `latest`, reuses the current task browser without a package-specific host adapter.
- Conversation rendering reuses official DSH Markdown, button and status components. Login-shell environment loading improves discovery of local executables while preserving the desktop launcher settings.
- SDK and Devkit assets are **0.1.0-alpha.3**. They are distributed as installable TGZ files; their npm package names are not published.

Download [macOS Apple Silicon (arm64) DMG](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/DSH-Deskwork-mac-arm64.dmg) or the [Linux x64 portable archive](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/DSH-Deskwork-linux-x64.tar.gz). macOS supports Apple Silicon only. Both packages include their own runtime and pnpm. Drag the macOS app into Applications; on Linux, extract and run `./linux-unpacked/dsh-deskwork`.

Checksums are in [SHA256SUMS](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/SHA256SUMS); [release-manifest.json](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/release-manifest.json) records the source commit, runtime versions and verification runs. Only desktop binaries, SDK/Devkit packages and integrity metadata are distributed.

Verification covers standard checks, external SDK/Devkit consumers, native session recovery, approval allow/reject/cancel paths, legacy history, plugin installation and the published ERP 0.1.1 consumer. The macOS arm64 DMG is mounted and installed outside the build directory, its signature is checked, and its packaged runtime is exercised without a system Node or pnpm on PATH. The Linux archive receives the same packaged runtime and integration checks. Uploaded asset hashes are checked before publication.

macOS uses ad-hoc signing; Developer ID signing and Apple notarization are not configured. Verification uses deterministic models and synthetic websites. Live-model business tasks and user macOS acceptance remain pending. Local plugins execute trusted code with access to files and the network.

## 中文

DSH Deskwork 0.2.2 完成与固定 **DSH 0.2.0-rc.2** 的原生会话及审批集成。DSH 上游仍为预发布版本。

- 重启后保留原生 DSH 工具历史。任务保持暂停，重新观察页面并明确继续后才恢复，旧审批失效；新建任务使用独立会话。旧的纯文本对话仍可查看，并明确提示无法恢复其工具历史。
- 关键浏览器操作及插件操作使用原生 DSH 审批。停止或拒绝任务会阻止待执行操作，确认后无需额外模型回合。
- 插件获取通用网站上下文，并显示实际加载状态；更新失败时保留原安装。通过 npm `latest` 发布的 ERP **0.1.1** 复用当前任务浏览器，宿主无需按包名适配。
- 对话渲染复用官方 DSH Markdown、按钮和状态组件。加载登录 shell 环境，改善本地可执行程序发现，同时保留桌面启动器设置。
- SDK 与 Devkit 为 **0.1.0-alpha.3**，以可安装 TGZ 分发，其 npm 包名尚未发布。

下载 [macOS Apple Silicon（arm64）DMG](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/DSH-Deskwork-mac-arm64.dmg) 或 [Linux x64 便携包](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/DSH-Deskwork-linux-x64.tar.gz)。macOS 仅支持 Apple Silicon。两种桌面包均包含独立运行时与 pnpm。macOS 将应用拖入 Applications；Linux 解压后运行 `./linux-unpacked/dsh-deskwork`。

校验值见 [SHA256SUMS](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/SHA256SUMS)，[release-manifest.json](https://github.com/GuoMonth/dsh-deskwork/releases/download/v0.2.2/release-manifest.json) 记录源码提交、运行时版本与验证运行。发布资产仅含桌面二进制、SDK/Devkit 包与完整性元数据。

验证覆盖标准检查、仓库外 SDK/Devkit 消费、原生会话恢复、审批允许／拒绝／取消、旧历史、插件安装，以及已发布 ERP 0.1.1 的联合消费。macOS arm64 DMG 挂载后安装至构建目录外，校验签名，并在 PATH 不含系统 Node 或 pnpm 时验证随包运行时。Linux 便携包接受同样的运行时与集成检查。发布前核对上传制品摘要。

macOS 使用临时签名，尚无 Developer ID 签名和 Apple 公证。验证使用确定性模型及合成网站；真实模型业务任务和用户 macOS 实机验收仍待完成。本地插件执行可信代码，可访问文件和网络。
