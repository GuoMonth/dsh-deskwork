## English

DSH Deskwork 0.2.0 aligns with pinned DSH 0.2.0-rc.2 and reuses native Browser Use, approvals, Sessions and Skills for ERP experience sharing. DSH upstream remains a prerelease.

- Download macOS Apple Silicon DMG or Linux x64 portable archive from this release. The app includes its own runtime and pnpm.
- Install the ERP plugin from `@guosheng_047/dsh-erp@latest` (currently 0.1.0). Experience export/import produces standard native Skills and binds imported knowledge to the recipient's ERP scope.
- SDK and Devkit TGZ assets retain version 0.1.0-alpha.2. Private integration plugins and business screenshots are not public release assets.
- Verified: 31 unit tests, 9 macOS source integration checks, DMG/signature validation and 8 packaged checks. Linux packaged checks and two clean users installing the published ERP latest, sharing experience and restarting passed.
- macOS uses ad-hoc signing; Developer ID signing and Apple notarization are not configured. Real-model business tasks and user macOS acceptance remain pending.

Metadata correction: private test material was withdrawn on 2026-10-01. Desktop binaries are unchanged; the manifest and checksums list only the remaining public assets.
