# PC 工作台功能冒烟 · 2026-09-08

范围：按用户要求确认功能，不评测模型完成率和效果。Linux x64 + Xvfb，真实 Electron、DSH 0.1.2-rc.1、DeepSeek 官方模型；源码为本记录所在提交。macOS 分发仍仅支持 Apple Silicon，本轮不重复打包评测。

## 已确认

- 用户授权的 Cookie 注入独立测试会话，商户身份接口与收支分类查询成功；真实批发后台可正常打开。关闭、重启 Electron 后保留登录。
- 真实 DSH 从批发首页读取快捷入口与记录类型，中文回答；该次请求约 3.7 秒、3 次模型请求、2 次工具调用，仅为一次功能样本。
- 提议打开「其他收支」→ 宿主确认 → 导航到目标页 → 读取查询区域与记录类型。共 6 次模型请求、4 次工具调用；总时间含人工确认等待，不作为性能指标。
- 停止后任务保持暂停，无后续工具调用；Copilot／Agent 使用同一页面和任务，Agent 隐藏原生网页，设置对话框可覆盖网页。
- 检查 1440×940、1366×768、1040×680 桌面尺寸，以及面板键盘调整、网址编辑、双入口切换。
- React 热更新保留草稿、Agent 视图和网页登录态；宿主开发入口连接实际 IPC，网页没有宿主桥。新增 `npm run dev:desktop` 支持 UI 热更新及宿主代码变化后重启。

## 修正与边界

修正首次加载时刷新使用空 URL、地址栏未跟随真实导航、空对话自动滚到底部、自定义可点击卡片缺失等问题。卡片通过通用 DOM 语义及指针样式发现，无站点专属选择器进入产品。未知卡片仍需确认。

`flow.html` 是网站内部模块，单独打开可能空白；从商户后台进入完整批发应用后可正常使用。快捷入口「其他收支」实际带 `addNote=true`，保留确认及结果核对是必要的。本轮未填写或提交业务记录，不能当成真实业务写入验收。

真实回复仍有表述不准确的样本，例如把当前记录中的值说成完整筛选选项。已加强提示约束，但按用户要求不继续评测效果，也不宣称已解决所有模型理解问题。跨域 iframe、复杂控件和所有 ERP 兼容性仍未覆盖。

确定性回归：`npm run check`，以及 `xvfb-run -a node --test tests/desktop.integration.ts tests/browser-boundary.integration.ts tests/runtime.integration.ts`。增加自定义卡片、当前页面地址、PC 空状态和模型实际收到系统指令的断言。

身份、模型密钥和业务截图仅保存在本机私有目录；仓库只保留脱敏结论。原始确定性日志在 `.artifacts/live-*.log`。
