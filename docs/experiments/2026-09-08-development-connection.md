# M3 开发连接与内置服务验证

环境：Linux、Node 24、Electron 44.2.0、DSH 0.1.2-rc.1。桌面夹具使用已授权本地隔离环境和 `--no-sandbox`。无真实业务身份、无真实模型密钥，写入仅发生在临时夹具。

## 通过的功能

- 真实 DSH 中，森果参考插件通过内置 `deskworkBrowser` 服务获得客户端并执行查询；没有安装用户插件时，默认开发 Skill 和文档工具仍可被模型调用。使用可控模型区分工具加载与真实模型效果。
- 真实 Electron 通过「插件 → 开发插件」界面生成 MCP 配置。独立 stdio 进程使用应用自带执行器读取随包指南，并连接已选定的网站，不需要系统 Node 或模型配置。
- 切换到第二个标签后，外部观察和动作仍命中第一个开发网站。已验证查询直接执行；保存前无提交，桌面确认后仅提交一次，外部状态标记待核对，刷新回读通过。
- 未核对前重复提出动作被挡住；断开后旧 MCP 工具调用被拒绝。单元回归覆盖跨页面拒绝、旧确认失效、任务恢复、凭据文件权限与删除、停止优先于排队动作。
- React 热重载预览中的开发入口、空配置和状态反馈可见，无浏览器控制台错误；真实 PC 界面截图位于忽略的 `.artifacts/desktop/m3-development.png`。
- 仓库外 SDK／Devkit 安装、文档读取、模板生成、类型检查和打包继续通过。

## 回归与复现

`npm run check` 执行格式、文档、类型、lint 和行为回归。`npm run build` 后，Linux 使用 `xvfb-run -a node --test tests/development-desktop.integration.ts` 验证完整开发链路；既有运行时、双站点、浏览器边界、原生插件与插件桌面测试也已通过。

原运行时模型夹具严格枚举旧工具列表，新增内置 Skill／文档工具后失败。更新预期集合后单独复验通过，没有放宽为任意工具。新开发连接的停止路径可中断执行队列；已发出的写入仍按原协议保留待核对，不能撤销网站已接收的请求。

macOS CI 和安装包回归已纳入开发连接测试；本地 Linux 证据不代替 macOS CI 或用户 Mac 实测。当前未发布新 DMG、开发包或市场版本。

## 边界

SDK 返回明确的确认暂停结果，但不恢复被中断的工具函数栈；插件作者在后续调用中读取事实，不能重放写入。外部 MCP 没有用户确认工具，确认／手动恢复仍在桌面进行。

开发连接是用户明确开启的可信本地扩展入口，使用同一宿主任务控制，不是操作系统沙箱。关闭 MCP 进程可重连同一会话；主动断开或退出桌面才撤销连接，重启不自动恢复。外部 AI 实际制作并公开发布第二个插件仍由 #18 跟踪。
