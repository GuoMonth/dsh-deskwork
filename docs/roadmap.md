# 路线图

当前阶段：开发规范与本地技术假设验证。未列出发布日期；以下待办均为计划能力。

## 0. 定义项目

- [x] 确定 DSH Deskwork 名称与产品定位。
- [x] 编写中英文 README、设计说明与 MIT 许可证。
- [x] 建立 AI coding 规范、强类型检查、统一格式与分层证据目录。
- [ ] 选择首个目标 ERP、测试账户与无敏感数据的验证流程。
- [ ] 确认 DSH 上游、集成版本与分发许可证要求。
- [ ] 验证桌面浏览器方案并确定首个目标操作系统。

验收：明确一个可测试的业务目标、技术选择与 DSH 集成方式。

## 1. Copilot 最小闭环

- [ ] 桌面壳、单个业务标签页和右侧对话区。
- [ ] 用户手动登录并保持会话。
- [ ] 集成 DSH，通过工具读取选定页面并完成查询任务。
- [ ] 展示执行步骤，支持暂停、接手和重新读取页面状态。
- [ ] 完成一条辅助填写流程，提交前展示内容并确认。

验收：在一个 ERP 中，用户登录后通过对话完成查询，以及一条经确认的写入流程；能在业务页面核对结果。

## 2. Agent + 业务 API

- [ ] 提供以对话为主的 Agent 界面。
- [ ] 切换模式保留任务上下文和明确的会话绑定。
- [ ] 为一个已验证的业务动作实现 API 工具。
- [ ] 登录过期时提示用户重新认证并恢复任务。
- [ ] 覆盖请求超时后的结果核对，避免重复业务写入。

验收：同一任务可以从 Copilot 切换到 Agent，通过选定会话的业务 API 完成并回读结果。

## 3. Agent + MCP

- [ ] 提供 MCP 连接与凭据配置。
- [ ] 支持连接检查、工具发现和工具范围选择。
- [ ] 支持只配置 MCP、不依赖 ERP 网页登录的任务。
- [ ] 展示工具执行结果与失败原因。

验收：用户配置一个 MCP 服务后，可在 Agent 模式独立完成一个业务任务。

## 4. 桌面预览版

- [ ] 整理已验证业务流程与连接器说明。
- [ ] 补充安装、开发、配置与故障排查文档。
- [ ] 检查凭据处理、第三方许可证与发行包内容。
- [ ] 发布首个目标操作系统的预览安装包。

验收：新用户可以按文档安装，连接受支持系统，并完成示例流程。
