# 路线图

当前发布：[Deskwork 0.2.2](https://github.com/GuoMonth/dsh-deskwork/releases/tag/v0.2.2)（2026-10-10）。安装包、精确依赖和已通过的检查见发布说明。

| 阶段                                                   | 已交付                                                                          | 剩余工作                                                                                 |
| ------------------------------------------------------ | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [M1：网站工作台](specs/m1-configurable-workspace.md)   | 网址配置、独立登录与对话、两种视图、原生会话恢复和关键动作确认                  | 真实模型业务任务、用户 Mac 验收                                                          |
| [M2：DSH 插件](specs/m2-dsh-plugins.md)                | 市场安装、网站挂载、加载状态、失败更新保留原安装；已发布 ERP 插件复用任务浏览器 | 市场收录与实际使用反馈                                                                   |
| [M3：插件开发套件](specs/m3-plugin-development-kit.md) | SDK/Devkit TGZ、模板、随包指南、原生 Skill 与外部 MCP 开发连接                  | [第三方 AI 独立开发、分发并安装执行](https://github.com/GuoMonth/dsh-deskwork/issues/18) |

进度分别在 [M1 #3](https://github.com/GuoMonth/dsh-deskwork/issues/3)、[M2 #9](https://github.com/GuoMonth/dsh-deskwork/issues/9)、[M3 #15](https://github.com/GuoMonth/dsh-deskwork/issues/15) 中维护。发布完成不等于真实业务验收完成。

后续优先级由使用结果决定：业务 API、用户配置 MCP、签名公证、自动更新及性能改进。先完成第三方开发验证，再决定扩展范围。
