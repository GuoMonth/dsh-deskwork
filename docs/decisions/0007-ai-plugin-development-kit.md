# ADR-0007：公开 SDK 与单一来源的 AI 开发指南

状态：接受。2026-09-08 用户同意转向第三方 AI 插件开发生态，并要求先搭架子。

## 选择

沿用 DSH 原生包与服务机制，提取公开 SDK，逐步把浏览器基础能力作为内置 DSH 服务提供。业务插件依赖公开接口，不需要复制宿主源码、管理浏览器连接或获取 Cookie。

开发指南随 Devkit 包发布；原生 DSH Skill 是短入口，MCP stdio 是外部 AI 的读取入口，二者读取相同文件。SDK 类型从源码生成，避免文档维护另一份接口。只读文档进程与实际浏览器开发连接分开；无须登录或启动桌面即可阅读指南。

## 理由与边界

只提供仓库文档会使外部 AI 难以找到本机版本对应的契约；只内置 Skill 不能让其他编程客户端自动获得内容。轻量文件／Skill／MCP 适配能同时满足两种场景，暂不引入检索服务、向量数据库或平台。

已有 Electron CDP 执行路径先复用，不为第三方开发套件切换 Browser Harness 上游。任务绑定与宿主介导的确认不是对受信任插件的系统沙箱。开发版本可破坏性调整，不建设兼容矩阵；能力清单区分已实现和待实现。

标准与工具必须由仓库外开发验证。一个参考插件用于验证开发流程，不将扩充第一方 ERP 目录作为主线。
