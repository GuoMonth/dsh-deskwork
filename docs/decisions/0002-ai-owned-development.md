# ADR-0002：AI 主导开发，降低反馈成本

状态：接受。日期：2026-09-05。来源：项目发起人对 PR #1 的修订意见。更新 [ADR-0001](0001-evidence-first-tooling.md) 的执行角色与实验政策，保留严格类型和兼容工具链。

## 决策

AI 负责完整的编码、测试、实验、文档维护和 PR 更新。人提供产品规格、必要的重大取舍与审核。例行工具选择、小范围类型适配和已授权环境中的实验由 AI 自主完成，不新增确认步骤。

大部分文档供 AI 按任务加载；人的主要入口是规格、架构决策与结果摘要。AGENTS.md 负责短路由，不要求每轮通读全部规范。局部 any 例外保留理由与边界测试，不强制单独 ADR。

本地已有外层隔离环境时，使用 host 模式关闭嵌套 Chromium sandbox，减少重复配置成本。实验报告记录模式；保留独立 chromium 模式供相关边界验证，不自动降级。临时会话、contextIsolation、禁用 Node 集成等原有测试条件继续保留。产品发布设置尚未决定。

独立检查并行执行，直接启动工具的 Node 入口，减少 npm 子进程。TypeScript 使用增量图，格式缓存按内容失效；typed lint 与测试每次执行。成功输出摘要，完整诊断写入 artifact。文档变更采用较小范围检查，代码变更完成时检查完整范围，CI 用同一套无缓存检查。

## 权衡

- 选择可验证的提速，暂不换运行时、编译器或包管理器，不引入新并行调度依赖或后台服务。工具跨平台使用参数数组启动，不依赖 shell 引号和 Unix 环境变量赋值语法；实际支持仍以运行环境记录为准。
- TypeScript 最新版超出 linter 的兼容范围，继续锁定已有兼容版本。强类型和错误传播不为提速让步。
- typed lint 不按单文件缓存，因为外部类型变更可能影响未编辑文件。格式缓存未来引入 Prettier 插件时必须复议失效策略。
- host 模式验证会话与 CDP 行为，不能支持 Chromium sandbox 或产品安全结论。旧实验失败与适配证据继续保留。
- 文档检查入口依赖 AI 根据 diff 正确选择；最终 CI 运行完整无缓存检查。当前固定五项独立工具可并行；项目增大后根据耗时和峰值内存重新评估并发。

性能与模式验证的实际结果追加到实验记录，不把预期收益当结论。若发现漏检、兼容回归或成本倒挂，回退到无缓存命令并保留失败证据。
