# M3：AI 插件开发套件

第三方 AI 使用公开套件，在独立项目完成插件创建、调试、发布和安装。交付状态见[路线图](../roadmap.md)，使用入口为 [Devkit](../../packages/plugin-devkit/README.md)。

## 设计

Deskwork 管浏览器会话、执行和确认；插件管领域知识与流程。SDK 提供类型和 Schema，公共浏览器服务通过 DSH 依赖注入使用。

指南只有一份，供本地文件、原生开发 Skill 和 MCP stdio 按需读取。精确接口由类型表达，指南解释约束与开发流程。

## 三个交付步骤

1. **开发骨架**：SDK、模板、指南、原生 Skill 和只读 MCP。在仓库外完成安装、创建、编译和打包。
2. **浏览器调试**：用户选择网站并明确开启外部连接，AI 使用当前页面，确认、停止和结果核对均可操作。
3. **第三方闭环**：AI 只靠公开套件制作第二个插件，发布并安装执行，宿主无业务改动。

内置原生工具通过 DSH approval 等待用户决定；外部 MCP 返回结构化暂停状态，不能代替用户确认。开发连接独占自动任务位置，重启后需要重新开启。

## 验收

- 宿主与 SDK 共用类型和 Schema；模板不引用仓库内部文件，不覆盖已有目录。
- TGZ 能在仓库外安装，不包含凭据、业务数据或开发机器路径。
- 文件、Skill 和 MCP 读取相同指南。MCP 不依赖 Electron 或模型密钥，文档访问限于已定义 ID。
- 分别证明模板构建、真实页面调试和发布后安装；编译通过不能代替后两项。

选择一个 DSH、SDK 和宿主版本验证，不承诺跨版本兼容。架构选择见 [ADR-0007](../decisions/0007-ai-plugin-development-kit.md)，已有证据见[开发骨架](../experiments/2026-09-08-plugin-devkit-foundation.md)和[开发连接](../experiments/2026-09-08-development-connection.md)。
