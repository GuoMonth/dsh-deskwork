# M2：DSH 插件工作台

用户通过现有市场安装标准 DSH 插件，将领域经验用于已配置的网站。交付状态见[路线图](../roadmap.md)，信任模型见 [ADR-0006](../decisions/0006-trusted-dsh-plugins.md)。

## 目标与边界

插件负责领域知识、适用条件与流程；Deskwork 负责网站会话、任务执行和宿主介导动作的确认。保留原生 Skill、插件格式和生命周期。

本地插件是用户信任的可执行代码，可访问文件和网络。浏览器确认只控制宿主介导的动作，不约束插件自身能力。安装需用户核对来源并主动信任。

选择一个 DSH 版本完成真实功能验证，不承诺跨版本兼容，不另建市场、ZIP 格式或适配层。

## 三个交付步骤

1. **安装与加载**：搜索市场或输入标准来源，完成安装、启停、更新及卸载，显示实际加载状态。
2. **挂载与调用**：唯一挂载名绑定网站，向插件提供通用浏览器上下文；运行任务的目标和插件版本保持固定。
3. **发布与使用**：仓库外制作标准 ERP 插件，发布后从市场安装，普通模型复用查询；验证桌面安装包。

步骤连续推进，探针随交付完成。影响当前任务的插件变更先停止或等待任务结束；更新失败保留原安装。

## 宿主接口

[SDK](../../packages/plugin-sdk/README.md) 提供当前网站的身份、名称和 URL，以及任务绑定的观察、动作和结果核对接口。业务配置与存储由插件管理，宿主不按包名注入 ERP 字段。

已验证只读查询可连续执行。写入、可能自动保存及未知影响先确认；页面变化后使用新观察，不复用旧元素引用。停止、拒绝或确认失效阻止待执行动作；已发送但结果不明的写入不自动重提。

## 验收

| 环节       | 通过条件                                                 |
| ---------- | -------------------------------------------------------- |
| 安装       | 标准市场来源可安装；加载失败显示原因，失败更新保留原版本 |
| 生命周期   | 启停、更新、卸载真实生效；影响任务的变更先停止或等待     |
| 网站与任务 | 唯一挂载名、通用上下文、固定目标及版本，恢复先观察       |
| 执行       | 查询可连续使用；确认允许、拒绝、取消均有行为回归         |
| 分发       | 外部制作的已发布插件可安装执行，宿主无需业务代码改动     |

历史 M2 结果见[阶段验证](../experiments/2026-09-08-m2-plugins.md)；后续原生集成见 [rc.2 验证](../experiments/2026-10-10-rc2-native-convergence.md)。这些记录不代表所有真实业务已验收。
