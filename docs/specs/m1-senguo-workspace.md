# M1：森果档口批发工作台

状态：实现与验证中；真实森果和用户 Mac 验收尚未完成。人审阅本规格、[视觉原则](../design/visual-system.md)与[集成决策](../decisions/0004-m1-desktop-integration.md)，AI 以代码契约和测试推进。

## 交付目标

macOS Apple Silicon 预览安装包，中文、单用户、单个测试店铺。默认入口为 <https://center.senguo.cc/#/main/shopList>，登录后进入档口批发。用户自行登录，任务使用同一会话。

首条业务：读取指定测试商品的基础资料，准备一个可逆非金额字段的修改，用户核对店铺、商品及前后值后保存，重新加载并回读服务端结果，再恢复原值。登录后才能确定真实字段和页面选择器；当前不发布猜测得到的森果写入适配。

Copilot 与轻量 Agent 共享任务和会话，视图切换不改变执行目标。Agent 仍使用同一业务浏览器。配置多个固定标签属于 M1；通用 MCP 设置、API 学习、自动技能生成与修复属于后续里程碑。

## 不可退化的验收条件

- 启动固定入口、用户登录、重启保留会话；页面没有宿主执行能力。
- 任务固定标签与会话，同一会话的自动操作串行；普通标签切换不重新绑定任务。
- 未确认不保存；确认只适用于同一店铺、对象、页面版本和原值。
- 停止撤销工具权限；已发出的写入进入核对状态，超时不得自动重放。
- 业务结果以服务端回读为准，模型文本不能使写入变为已验证成功。
- 本地技能按系统、会话、店铺、字段、页面版本识别适用性；只在结果验证后记录成功经验。
- 安装包自带 DSH 与工具桥，模型密钥使用系统安全存储；业务会话、任务、技能在独立用户数据目录保留。

## 验证分层

确定性测试覆盖确认、身份变化、停止、结果不明及技能失效。本地 ERP 夹具使用真实 HTTP、持久 cookie 和 Electron 页面；DSH 协议测试使用真实发布包及可控模型端点。两者都不能替代真实森果与 DeepSeek 的验收。

macOS CI 负责 arm64 构建和可自动化的桌面检查，用户 Mac 负责实际安装路径、手动登录和真实业务操作。安装包为未签名、公证前的预览版。

## 实测输入

待提供：测试店铺名称、允许修改并恢复的测试商品、可用的 DeepSeek 连接配置。密码与密钥只在本地输入。AI 在获准的测试范围内勘察字段、固化适配并执行验证；无需用户参与日常代码和测试实现。
