# M1：可配置的网站工作台

用户添加日常网站，在原页面登录，通过旁边的 AI 对话完成工作。产品不要求 ERP 连接器、字段映射或预装业务模块。交付状态见[路线图](../roadmap.md)；范围选择见 [ADR-0005](../decisions/0005-configurable-workspace-scope.md)。

## 用户看到的结构

- 一个网址对应一个固定标签，名称可选；可添加、编辑、移除，重启后保留。首次启动为空工作台。
- 网站保留自己的样式和导航。页面跳转与登录弹窗归属原入口；移除入口不删除网站业务数据。
- 各入口有独立登录和对话，用户无需填写内部会话标识。
- Copilot 并排显示页面与对话；Agent 展开对话，仍使用同一任务和浏览器。
- 同一时间运行一个自动任务，其他入口可以手动浏览。切换标签不改变任务目标。
- 界面支持 English 与中文，首次启动默认跟随系统首选语言；无支持语言时回退 English。可手动覆盖，偏好本地保存，升级保留已有语言选择；更改系统语言后重启生效。界面与后续模型任务使用同一语言，历史对话与网站正文保持原文。
- 托盘提供打开窗口、任务状态和退出。关闭窗口隐藏并保留任务及待确认操作；退出停止运行时、保存任务并清理进程。托盘不可用时关闭窗口执行退出清理。

## 执行与结果

浏览器工具观察、定位、导航、点击、填写、滚动并读取结果，绑定当前任务页面。

确认展示目标页面、具体动作和受影响输入。普通观察、滚动和可识别的普通链接可连续执行；关键动作、未知副作用、可能自动保存的输入先确认。键盘确认绑定焦点和按键，焦点变化使确认失效。模型声明不能降低宿主判定的风险。

停止或人工接手会暂停后续自动动作。恢复先重新观察，旧确认不复用。停止不能撤回已发出的请求；超时或断连后，结果不明的写入保持待核对，不自动重提。

自动核对只接受用户已确认的预期正文：刷新后出现，且操作前不存在。输入框的新值和模型文字不能证明已保存；其他结果由用户在网站上核对。

## 验收标准

| 编号              | 通过条件                                                                            |
| ----------------- | ----------------------------------------------------------------------------------- |
| A1 配置即接入     | 空状态下添加、编辑、移除 1–3 个网址，重启后标签一致；接入另一网站只改配置           |
| A2 原样浏览与身份 | 两站点及同源双入口登录隔离；跳转和弹窗归属原入口，网站没有宿主桥接权限              |
| A3 共享任务       | 视图、标签和面板变化保留任务；停止后无后续动作，恢复先观察                          |
| A4 通用操作闭环   | 真实 DSH 与 Electron 在两个结构不同的网站完成读取、输入、确认及结果核对             |
| A5 异常与确认     | 确认前无提交；页面、身份、输入或焦点变化使确认失效；响应丢失不重提                  |
| A6 实机交付       | 安装包自带运行时，完成配置、登录、任务及重启；真实模型、网站和用户 Mac 分别记录结果 |

公开回归使用合成网站。真实业务写入只在获准对象上执行并恢复数据，不能用夹具结果代替实机验收。证据见[实验记录](../experiments/README.md)。

## 范围之外

M1 不包含垂直业务技能、知识自动学习、业务 API 接入、用户配置 MCP、自动更新或 Apple 公证。特殊控件和认证流程的支持范围以实测为准。
