# DSH 插件宿主

状态：方向已接受；实现与功能验证按 [M2 规格](../specs/m2-dsh-plugins.md)推进。决策来源：[ADR-0006](../decisions/0006-trusted-dsh-plugins.md)。

## 产品关系

Deskwork 提供通用工作台、网站会话和浏览器执行接口；DSH 插件承载可选的 Skill、页面与业务知识、工具和流程。外部高能力 AI 制作插件，用户从既有市场安装后，普通模型按需使用。不把某个 ERP 的领域模型写入宿主，也不要求先安装插件才能打开网站。

插件身份与版本沿用 DSH／包生态；宿主只维护唯一挂载名、网站绑定和用户配置。安装表示代码已在本机可用，挂载表示该配置实例参与特定网站任务；取消挂载不删除网站或登录身份。名称冲突必须显式拒绝，不能依赖原生技能同名优先规则静默覆盖。

## 信任与执行责任

用户主动安装并信任本地扩展，插件可以执行代码，具有运行环境允许的本地访问能力。安装界面说明来源、版本与这个边界；没有基于能力声明的系统权限沙箱。插件卸载不承诺撤销其已产生的外部副作用。

Deskwork 提供任务目标、页面观察、动作、停止和结果接口；通过这些接口的写入继续执行宿主确认与核对。接口不主动传出 Cookie 或 Electron 对象，但不能因此声称任意 Node 插件无法读取文件、使用网络或绕过浏览器接口。网站绑定是协作插件的作用域契约，不是不可信代码的隔离证明。

## 生命周期与开源迭代边界

可分发插件、安装依赖与锁文件、用户配置和运行记录分开保存，更新不覆盖用户数据。插件安装环境位于用户数据目录，不修改应用安装包。更新失败回到上一个可加载环境；业务数据回滚不属于包管理回滚。

运行任务不热换插件版本。受影响的更新、禁用、取消挂载或卸载等待任务完成或先停止；必要时重启运行时。新任务按新环境加载，恢复任务重新观察并核对上下文。

复用 DSH 原生加载与生命周期，不建设另一套插件引擎。只打通本轮选定的市场、DSH 版本与样例插件，不承诺任何版本兼容性，不建设兼容矩阵、认证或通用适配层。遇到实际依赖问题可以直接升级并锁版本，安装失败显示真实错误；精简记录实际测试版本即可。标准包字段和必要的 Deskwork 接口版本用于解析与开发，不构成稳定 API 承诺。
