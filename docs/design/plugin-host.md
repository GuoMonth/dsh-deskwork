# 插件宿主设计

产品范围见 [M2 规格](../specs/m2-dsh-plugins.md)，可执行扩展的信任选择见 [ADR-0006](../decisions/0006-trusted-dsh-plugins.md)。

## 安装、挂载与数据

DSH 管插件格式和原生生命周期。Deskwork 管唯一挂载名、网站绑定及用户配置：安装使代码在本机可用，挂载让某个配置实例参与网站任务。取消挂载保留网站和登录资料，名称冲突明确报错。

插件环境在用户数据目录，安装和更新不改应用包。可分发代码、依赖、配置与运行记录分开保存。更新失败保留原可加载环境；包回滚不回滚业务数据。

## 执行责任

插件从通用网站上下文获取身份、名称和 URL，自行管理业务配置与存储。宿主不识别业务包名，不注入 ERP 字段。类型和调用方式见 [SDK](../../packages/plugin-sdk/README.md)。

任务运行期间不热换插件版本。影响任务的更新、禁用、取消挂载或卸载需等待结束或先停止；恢复后重新观察。

宿主介导的浏览器动作遵循任务确认和核对。网站绑定是协作范围，本地插件仍可使用文件和网络；卸载也不能撤销已产生的外部副作用。
