# DSH Deskwork 设计说明

状态：[M1 通用规格](../specs/m1-configurable-workspace.md)已获用户批准并实现，真实使用验收中。本文维护概念与长期方向，技术结论以决策和实验为准。

## 产品边界

DSH Deskwork 是面向日常 ERP 操作的桌面工作台。用户配置网站，网站提供业务界面，DSH 借助浏览器能力协助用户完成任务。Deskwork 不重新实现 ERP 页面，不预设采购、库存、店铺或商品导航，也不要求每接入一个 ERP 都开发连接器。

用户最少只需配置网址，名称可选。一条网址配置就是一个工作区入口，以固定标签呈现；内部的会话、host 与进程组织不增加用户概念。

## 核心概念

| 概念       | 职责                                         |
| ---------- | -------------------------------------------- |
| 工作区入口 | 用户配置的网址与名称，对应一个固定标签       |
| 浏览器会话 | 内部保存该入口的身份、页面和登录跳转上下文   |
| 任务       | 用户目标、绑定入口、步骤、确认与结果         |
| DSH 运行时 | 对话、任务组织和对宿主工具的调用             |
| 浏览器工具 | 在绑定页面观察、导航、点击、填写和读取结果   |
| 本地经验   | 后续按站点与场景积累的可选技能，不是接入前提 |

## 两种视图，一个任务

Copilot 在原网站旁展示对话。轻量 Agent 以对话为主，保留目标网站并可随时「查看页面」。用户自行登录，自动操作使用相同会话；切换视图不重启任务，切换普通标签也不静默改变运行任务的目标。

界面展示目标、步骤、待确认动作与可核对结果。业务对象和字段来自页面与当前任务，不成为工作台的固定栏目或通用协议必填字段。需要登录、动作影响不明确或执行遇阻时，让用户直接在原页面接手，恢复前重新观察。

视觉系统只覆盖 Deskwork 外壳，网站保持原样；预览重点展示入口配置、页面承载和对话状态，不绘制仿制 ERP 页面来填充产品设计。

## 会话与执行边界

凭据留在宿主，模型使用会话引用。默认每个入口具有独立持久身份，SSO 与弹窗在该入口内衔接；可配置共享会话属于后续。网页没有桌面宿主和运行时执行权限，模型工具只定位本应用拥有、任务已绑定的页面。

任务区分运行、等待用户、暂停、成功、失败、结果待核对和取消。提交确认绑定实际动作及目标状态，状态变化时重新确认。停止撤销后续自动动作；已经提交但未收到响应时，先核对实际状态，不自动重复写入。通用动作下的实现边界见 [H-008](../hypotheses/h008-configured-site-operation.md)。

## 后续扩展

先让浏览器通用操作可用，再积累可验证技能。业务 API 与用户配置 MCP 是后续执行路径：API 需验证认证和语义，MCP 可使用独立身份，不默认继承浏览器凭据。无论采用哪条路径，任务目标、确认和结果核对语义保持一致。

不在 M1 预建连接器平台、插件市场或自动进化框架。Electron、DSH 与 CDP 的已有证据保留，Browser Harness 的替换依据继续通过实验形成。产品边界纠偏见 [ADR-0005](../decisions/0005-configurable-workspace-scope.md)。
