# 本地经验资产包

状态：2026-09-08 用户明确要求的交付形态；格式和执行协议尚未定稿。属于 M2 经验层，当前 PC 工作台调试不引入包运行框架。

## 用户要求

某个 ERP 系统、菜单或业务域的知识与操作经验可以形成独立资产包，类似 skill ZIP。包可在本地展开、注册挂载使用，也可取消挂载、升级和替换。注册挂载名全局唯一。

网站仍通过网址配置接入。业务知识属于可插拔资产，不进入工作台通用协议，也不是打开新网站的前置条件。

## 设计约束

- 包标识和版本描述分发内容；唯一挂载名标识本机启用的注册实例。名称冲突必须显式处理，不能静默覆盖。
- 安装、挂载、取消挂载分开：取消挂载使包不再参与新任务，不等于删除网站或登录身份。
- 包与网站入口绑定关系保存在本机。可复用包不携带用户 Cookie、模型密钥或测试账号身份。
- 升级和替换保留清晰的版本边界；运行中任务绑定原版本，新任务使用切换后的版本。升级失败保留原可用版本。
- 可分发内容与用户运行记录、个人参数及后续积累分开保存，替换包不覆盖用户积累。
- 经验提供适用条件、输入输出和结果判据；挂载经验不能绕过宿主确认、目标隔离和结果核对。

压缩包布局、强类型清单、兼容版本判定、运行表达方式和升级迁移机制在 M2 实验后确定。先验证一个包的安装、唯一名称注册、挂载、执行、取消挂载与替换闭环，再扩大到组合和自动进化。
