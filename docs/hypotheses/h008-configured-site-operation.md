# H-008：仅通过配置接入的网站可由同一浏览器能力操作

状态：普通 DOM、双站点、可控模型的集成范围内支持；真实模型及复杂页面尚待验证。证据见 [2026-09-06](../experiments/2026-09-06-configurable-mvp.md)。

## 假设与判据

不新增源码、选择器映射或业务 schema，仅通过网址配置接入两个结构不同的网站，同一套浏览器工具可完成观察、定位、导航、填写、提交确认与结果核对。任务目标不因切换标签或弹窗而漂移，停止后不再执行后续动作。

## 最小实验

使用真实 Electron 页面和 DSH 进程，把运行时、模型工具调用与实际页面变更串成一条集成测试。两个本地测试站点采用不同页面布局和表单对象；工具只获取运行时页面信息，不能预置其中的业务选择器。可控模型验证协议与宿主边界，真实模型另测未知页面的定位质量和完成情况。

必须加入负例：导航／点击被错误标为无副作用、填写引发自动保存、提交前页面或输入已变、登录失效、用户接手、请求已提交但响应丢失。确认绑定待执行动作和页面状态；未知按钮和可能自动保存的输入默认请求确认。无法操作或无法可靠核对时转交用户。宿主规则覆盖已定义的 DOM 语义，不能证明任意网页脚本没有隐藏副作用。实验需记录如何实现此边界及其实际覆盖范围，不能把提示词约束当成证明。

先覆盖基础页面与普通表单；再验证 iframe、登录弹窗和目标恢复。真实网站以森果等配置样例单独记录；夹具通过不等于所有 ERP 兼容。

## 结论规则

通过后才能将对应能力标记为 M1 已验收。若关键动作无法稳定定位或确认，应明确缩小可自动执行的动作范围并提交人审阅；不能自动退回按 ERP 开发产品模块。

结果记录放入 `docs/experiments/`，注明源码身份、环境、模型、测试网站、动作范围和失败情况。已有 [M1 集成记录](../experiments/2026-09-05-m1-integration.md)只证明旧资料工具／夹具的局部能力。
