# H-009：DSH 插件市场可接入独立桌面运行时

状态：**待验证**。接受的是插件路线与本地扩展信任模型，尚未完成市场／安装包／原生插件串联实验。

## 假设与失败判据

| 假设                           | 最小实验                                                                 | 不支持的信号                                                               |
| ------------------------------ | ------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| 既有市场可为桌面提供安装入口   | 固定候选版本，验证发现、标准包来源与管理接口；比较服务适配和管理界面嵌入 | 只能完整替换工作台为 DSH Web；依赖不可用私有接口或另建注册中心             |
| 当前 SDK 可以加载标准插件      | 最小 DSH bundle/patch、原生 Skill／附件和一个工具在真实进程调用          | 只写提示文本而未加载插件；服务依赖缺失；安装 profile 与运行 profile 不一致 |
| 安装包可独立管理依赖           | arm64 DMG 复制到仓库外，无系统 pnpm，安装／更新／卸载插件后重启          | 样例安装依赖开发仓库、用户预装工具或修改应用签名内容；失败破坏旧环境       |
| 原生生命周期支持网站挂载       | 双网站、重名、运行中更新请求、停任务后切换与重启恢复                     | 静默覆盖同名挂载、目标或版本中途变化、取消后新任务仍加载                   |
| 插件流程减少查询模型往返       | 同一普通模型执行无插件／安装后／再次使用的小样本                         | 查询依旧反复确认、结果错误或工具内部仍逐步请求模型                         |
| 页面变化和停止能被宿主接口处理 | 改夹具定位／页面条件，中途停止多步查询                                   | 错点、盲目继续、停止后仍执行宿主步骤或重复提交                             |

## 实验约束与记录

从 DSH `0.1.2-rc.1` 起步，直接选定一个市场并打通；遇到功能阻塞可以升级依赖，记录本轮锁定版本。探针随开发完成，不设独立兼容审查阶段，不测历史版本或全市场插件。使用现有热重载和真实进程，主要验证功能；凭据和业务数据不进入插件、仓库或公开证据。

原生 Skill 优先验证注册、按需读取与销毁，不另造知识加载引擎。网站可见性与任务作用域按协作插件契约验证，不能据此宣称隔离任意本地代码。任意插件的独立网络操作不纳入宿主浏览器确认覆盖率。

每次结论写入 `docs/experiments/`，记录提交、平台、版本、是否真实模型、样例插件版本与实际未通过项。分开 Linux、macOS CI、真实网站和用户 Mac 证据。当前文档不是通过证明。

[M2 规格](../specs/m2-dsh-plugins.md)定义退出判据；[ADR-0006](../decisions/0006-trusted-dsh-plugins.md)固定产品边界。自动生成、修复、晋升及普遍性能收益不在本假设范围。
