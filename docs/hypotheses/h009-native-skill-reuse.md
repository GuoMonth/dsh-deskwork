# H-009：原生 DSH Skill 支持网站资产复用与查询提速

状态：**待验证**。已阅读当前 `0.1.2-rc.1` 的 Skill 注册、文件提供器和模型加载工具源码；尚未完成 Deskwork 内的原生 Skill 集成实验。

## 假设与失败判据

| 假设                             | 最小实验                                                                        | 不支持的信号                                                           |
| -------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 原生组件可用于独立 SDK 运行时    | `sdk-minimal` + Deskwork MCP + 一份外部 Skill，模型读取正文及知识附件并完成查询 | 只能使用 Web profile；加载依赖任意 shell；附件无法受限访问             |
| 技能隔离和生命周期可表达产品语义 | 双入口不同目录，注册重名，卸载／升级，跨重启与任务恢复                          | 另一网站可读取或执行技能；旧任务版本静默变化；卸载后新任务仍获执行权限 |
| 已验证经验可以降低查询等待       | 同一普通模型、目标、网站，比较无包／首次挂载／复用                              | 查询仍反复确认、结果错误，或模型调用没有减少                           |
| 页面变化可停止错误复用           | 修改夹具目标元素或页面适用条件，重复调用原流程                                  | 错点、继续执行不匹配步骤、自动重复写入                                 |

## 实验约束

- 使用现有热重载实例和本地夹具，真实网站只做已授权查询；凭据与业务数据不入仓库或知识包。
- 原生组件负责目录和加载；网站绑定、唯一挂载名、版本固定与写入确认由宿主执行。
- 先试关闭默认目录扫描并配置任务专用技能目录；隔离不足时实现薄提供器适配，继续复用注册器和加载工具。
- 若只将正文注入提示、仍逐步执行，应记录为知识辅助，不能宣称已实现流程加速。
- 指标区分模型调用、工具调用、页面观察和人工等待；不设未经测量的百分比收益目标，不扩大为效果评测项目。
