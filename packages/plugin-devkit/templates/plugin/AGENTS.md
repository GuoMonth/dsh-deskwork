# Plugin author contract

Use the public Deskwork SDK and standard DSH plugin lifecycle. Read the Devkit `workflow` and `contract` documents through local files or the configured development MCP before adding browser actions. The generated README contains build and installation commands.

Keep strict TypeScript and explicit input schemas. Express business prerequisites, result scope and evidence in the tool. Pass the execution signal, reobserve after actions, and stop on ambiguous pages. A confirmation pause is not success; do not automatically retry writes.

Keep credentials and business records out of source and package contents. Validate the smallest useful real behavior, then build and inspect the package. The starter SDK dependency points to a local archive; replace it with an available public source before publishing. Follow the user's authorization for publication and website mutations.
