# Website plugin starter

This standard DSH plugin reads the task page through the builtin `deskworkBrowser` DSH service and public SDK types. Install dependencies, run `npm run check`, then `npm run build`. Install the local directory in Deskwork and bind it to a website you have opened and logged into.

Use the development kit's `workflow` and `contract` guides before implementing business actions. Replace the example tool name and describe actual page prerequisites, parameters, evidence and incomplete results. The starter performs no write actions. Package with `npm pack`; before public release replace the local SDK archive dependency with a published version or a public archive URL.
